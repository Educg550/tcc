# Caronte

Na mitologia, poucos foram os que ousaram descer aos domínios de Hades e retornar — entre eles, Orfeu, Heracles (Hércules), Teseu, Éneas e Odisseu. Guiados pela coragem e pela necessidade de cumprir seus destinos, enfrentaram as profundezas e emergiram transformados.

Inspirado nessa jornada mítica, o sistema **Caronte** conduz os candidatos através dos labirintos da inscrição — formulários, documentações, etapas — como uma travessia simbólica rumo ao conhecimento.

Ao final, como os heróis que retornam do submundo, o estudante ressurge pronto para iniciar uma nova etapa: a pós-graduação, o mestrado ou o doutorado.
